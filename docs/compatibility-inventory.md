## Installation and opt-in commands

The minimal tmux setup is:

```tmux
set -g prefix C-Space
set -g mouse on
set -g history-limit 200000
run-shell 'mox init --apply'
```

`mox init --apply` installs generated Mox bindings/status/scroll configuration. It is not a TPM loader. `Mox`'s independent workflows are opt-in commands: `mox projects [--root PATH]`, `mox palette`, `mox editor setup` (Neovim Lua setup/registration), `mox persist save|restore|autosave|autorestore`, `mox log start|stop|save|clear`, `mox lazygit`, `mox clipboard`, and direct `mox extract` / `mox flash` / `mox nav`. Optional zoxide and desktop clipboard/open tools are capability fallbacks, not hard requirements for the CLI to start.
